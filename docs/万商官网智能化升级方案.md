# 万商官网智能化升级方案

2026 年 10 月 31 日

本次升级不改动网站现有的外观，主要做三件事：给网站加一个智能助手；把产品资料、站内搜索和询价单改造成一套统一的结构；整套结构以后扩展到其他行业的产品时，不需要重新开发。

## 升级一览

| 方面 | 现在 | 升级后 |
| --- | --- | --- |
| 智能助手 | 没有 | 网站右下角新增对话面板，客户可以直接提问、比较产品，并在面板里提交询价 |
| 产品参数 | 只适合填车轴参数，悬挂、轮毂、刹车鼓、支腿等无处填写 | 每个产品类别在后台配置自己的参数清单，任何品类都能完整录入 |
| 产品分类 | 只有一层 | 支持多级分类，例如"挂车配件 → 车轴 → 美式车轴" |
| 站内搜索 | 只能整句匹配，客户输入几个词就搜不到 | 拆词搜索、识别数字和单位、容错、同义词，结果按相关程度排序 |
| 询价单 | 技术栏目固定为车轴参数 | 技术栏目随客户选择的产品类别自动变化 |
| 常见问题 | 写死在网站里，员工无法修改 | 在后台管理，网站和智能助手共用同一份内容 |
| 产品用途 | 选项写死在网站里 | 完全在后台管理 |
| 计量单位 | 只支持重量和长度 | 默认使用磅、英寸，客户可切换为公斤、毫米；单位种类扩展到体积、功率、压力等 |
| 多语言 | 仅英文 | 智能助手用客户的语言回答；产品资料预留多语言版本 |

本次只改功能，网站的外观、页面布局和现有文字保持不变。

## 智能助手

智能助手由 DeepSeek 大模型驱动，只能查阅网站已经公开发布的资料，帮助客户找产品，并把需求整理成询价单。

**外观与入口**

- 网站右下角只保留一个入口。点开后，从右侧滑出对话面板，客户可以一边看产品一边提问。
- 面板里同时放着人工联系方式（WhatsApp、邮件、电话），不再另设一个按钮。
- 打开时会先给出几个快捷问题，客户点一下就能直接提问，例如"帮我选一款产品""询价需要准备哪些信息"。
- 快捷问题会跟着客户所在的页面变化，员工可以在后台为首页、产品页、询价页分别设置。

**能做什么**

- 回答产品问题、按客户描述的用途和参数推荐产品、对比不同型号。
- 每个回答下方附上它实际参考过的产品页链接。链接由系统按实际查到的内容生成，助手无法自行编造。
- 客户信息不足时会追问；资料里查不到答案时，引导客户联系人工。
- 需求说清楚后，在面板里生成一张预填好的询价单。客户核对、勾选同意隐私条款、通过人机验证后即可提交，全程不用离开面板。
- 客户用西班牙语、葡萄牙语等语言提问，助手用同样的语言回答。
- 回答一边生成一边显示，客户不用等到整段写完。

**不会做什么**

- 不能修改网站的任何数据，也看不到草稿、已下架产品、其他客户的询价和后台备注。
- 不替公司承诺价格、交期、产品性能或认证，这些由业务人员确认。
- 不替客户自动提交询价，必须由客户本人确认后提交。
- 客户在问题里夹带的指令，例如要求它读取内部资料，不会被执行。

**防刷与费用控制**（以下初始值均可在后台调整）

| 项目 | 初始值 |
| --- | --- |
| 每位访客每天提问次数 | 10 次 |
| 同一网络地址每天提问次数 | 25 次 |
| 单个问题长度 | 500 个字符 |
| 回答一个问题时查阅资料的次数 | 最多 5 次 |
| 回答总时长 | 不限制 |
| 连续无响应多久自动断开 | 30 秒 |
| 每日总费用上限 | 由贵方设定，到达后当天暂停，次日自动恢复 |

为降低费用，每次只把回答所需的资料发给大模型，并充分利用服务商对重复内容的优惠计价。

**稳定性**

- 助手独立运行。即使提问的人很多，或者大模型服务变慢，客户浏览产品和提交询价也不受影响。
- 后台设有总开关，关闭后助手入口立即隐藏，网站其他功能照常使用。
- 大模型服务暂时不可用时，向客户显示清楚的提示，并引导他们填写询价单或联系人工。

## 产品资料

产品参数改为"按类别配置参数清单"，全站只用这一套结构。以后增加任何行业的产品，都只需在后台配置，不需要重新开发。

- **参数清单**：后台为每个类别定义它有哪些参数，例如支腿的行程、承重、安装高度。每个参数定义好名称；填数字、填文字还是从选项里选；使用哪类单位；是否必填；是否用于网站筛选；是否在询价时询问客户。
- **录入产品**：员工选定类别后，对应的参数格子自动出现，只需填写数值。参数名称事先统一，不会出现同一参数有几种写法的情况。
- **多级分类**：分类可以分为大类和小类，小类可以继承大类的参数清单。
- **初始分类**：采用公司提供的 6 个类别——挂车车轴、悬挂系统、轮毂、刹车鼓、汽车配件、挂车支腿。
- **产品用途**：例如按车型划分的用途，完全由后台管理，初始为空。尚未添加用途时，网站不显示该栏目。
- **一处录入，多处使用**：网站产品页、筛选、站内搜索、询价单和智能助手，读取的都是同一份产品数据。

## 站内搜索

搜索框不调用大模型，客户输入即出结果，也不产生额外费用。描述型的需求，例如"海边使用、防锈好的车轴"，由智能助手回答。

1. **拆词搜索**：一句话拆成几个词分别匹配，不再要求整句一字不差。
2. **识别数字和单位**：客户输入"3500 lb""95 mm"时，自动按载重、尺寸条件筛选，磅和公斤、英寸和毫米自动换算。
3. **容错**：拼错一两个字母也能搜到。
4. **扩大搜索范围**：产品详细说明、产品参数、资料文件标题和新闻都能搜到。
5. **结果排序**：型号或编号完全吻合的排在最前，其次是标题吻合，只在说明里出现的排在后面。
6. **同义词后台维护**：例如英式和美式拼写、同一配件的不同叫法，员工可以自行添加。
7. **记录没搜到结果的词**：后台可以查看客户搜了什么却没找到，用来补充同义词或产品。只记录同意网站统计的访客。

## 询价单

询价单的技术栏目改为随产品类别变化，任何品类的客户都能填写自己需要的参数。

- 客户先选择要询价的产品类别，技术栏目自动显示该类别的参数。一张询价单可以同时选择多个类别。
- 显示哪些参数，由员工在后台的参数清单里勾选。
- 数量、交货日期、目的港、附件、补充说明等通用栏目保持不变。
- 从产品页或智能助手进入时，类别和已知参数自动预填。
- 现有的防机器人验证、防重复提交、附件杀毒和邮件通知机制全部保留；从智能助手提交的询价也走同一套流程。
- 客户所选产品自身的参数单独保存，不再与客户提出的需求混在一起，销售跟进时更清楚。

## 产品资料库与常见问题

智能助手的知识来自一份由系统自动生成的产品资料库。内容与网站已发布的数据完全一致，产品一有修改或下架，资料库立即同步更新。

- **包含的内容**：已发布的产品及其参数、产品类别、产品用途、公司介绍、新闻、常见问题、知识条目。
- **常见问题改为后台管理**：员工可以自行增删改，网站页面和智能助手使用同一份内容。
- **新增"知识条目"**：用来写网站页面上没有、但希望助手了解的内容，例如尺寸测量方法、包装方式、询价流程。
- **资料文件**：文字版资料自动提取文字；图纸、扫描件可由员工补充一段文字说明。
- **产品增多后照样可用**：助手先用站内搜索找到相关内容，再逐页细读，产品从几百个增加到几千个也不受影响。

资料库按固定格式生成，不由大模型改写，确保参数准确、不产生额外费用。

## 多语言与单位

- **多语言**：本次先做两项。一是智能助手用客户的语言回答；二是产品名称、说明、参数名、类别、常见问题和知识条目都预留多语言版本，目前先填英文，未填译文的内容自动显示英文。网站菜单和页面文字的翻译，将在以后重新设计网站界面时一并完成。
- **单位**：网站默认显示磅和英寸，客户可以切换为公斤和毫米。默认单位是后台的一项设置，以后可以随时更改。员工录入时用哪种单位都可以，系统统一换算。单位种类从重量、长度扩展到体积、功率、压力、温度、电压等，满足跨行业产品的需要。

## 隐私与对话记录

客户向智能助手提出的问题会发送给 DeepSeek 处理，对话内容按下表保存。助手面板打开时会提示"对话内容会被保存"，网站隐私政策也会同步补充说明。

| 对话类型 | 保存期限 | 处理方式 |
| --- | --- | --- |
| 普通咨询 | 90 天，到期自动删除 | 用于了解客户关心的问题、检查回答质量 |
| 客户留下联系方式，但未提交询价 | 1 年，到期自动删除 | 后台标为"潜在客户"，销售可主动联系 |
| 客户提交了询价 | 与询价单一同长期保存 | 关联到该询价单，销售跟进时可以看到客户先前的提问 |

- 客户在对话中留下联系方式时，助手会主动询问是否需要生成询价单，引导客户经确认后正式提交。
- 员工可以在后台把助手的回答标记为"答对"或"答错"，答错的单独列出，便于集中修正资料。
- 保存期限均可在后台调整。

## 其他细节修正

- 按载重筛选时，以公斤标注的产品不再被漏掉。
- 后台"重新扫描附件"改为排队执行，点击后立即返回，扫描完成后自动更新结果，附件较多时不会卡住。
- 产品资料下载链接统一，出错时返回的信息格式保持一致。
- 演示数据按新结构重写，只用于测试，不会混入正式的产品类别。
- 后台管理系统的标题更正为万商。
