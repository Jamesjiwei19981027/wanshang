## 实现概要

- **参数清单**：新增 `SpecField`（类别的参数定义）和 `ProductSpecValue`（产品的参数值）。数字参数同时保存录入值、录入单位和基准单位值，筛选、搜索按基准值比较。分类增加上级分类和"继承上级参数"。旧的车轴专用字段由迁移 0022 自动搬入参数清单后删除（已在 PostgreSQL 上用旧结构数据实测）。
- **单位**：`catalog/units.py` 支持重量、长度、体积、功率、压力、温度、电压、电流、扭矩、力、速度。录入单位原样显示，换算值按约四位有效数字显示。
- **后台**：类别页内编辑参数清单；产品页选定类别后自动出现参数格子（换类别时提示后重新载入）；新增常见问题、知识条目、同义词、没搜到的词、助手设置、快捷问题、对话记录和回答审核。附件重扫改为排队执行。资料 PDF 上传后自动提取文字。
- **搜索**：`catalog/search.py` 拆词、识别"数值+单位"、拼写纠正、同义词、按吻合程度排序，覆盖产品说明、参数、资料标题和新闻。产品的搜索文本随产品、参数、资料、用途、分类改动自动重建。新接口 `/api/search/`。
- **询价单**：技术栏目按所选类别的"询价时询问"参数生成；询价单保存所选类别；产品自身参数作为快照单独保存；用途只接受后台已发布的用途或"其他"；参数校验在人机验证之前完成。销售邮件中的参数改为可读格式。
- **助手**（`backend/assistant/`）：DeepSeek 流式调用，只有三个工具：站内搜索、读取已发布页面、生成询价单草稿。参考链接由系统按实际读取的页面生成。限额、每日费用上限、总开关、30 秒无响应断开、空回答和服务故障时给出清楚提示并退回当次额度。对话按保存期限每天自动清理一次（也可手动 `purge_assistant_conversations`）。
- **部署**：生产编排新增 `assistant` 服务（同一后端镜像，独立 uvicorn 进程，默认 64 并发），nginx 将 `/api/assistant/` 转发到该服务，聊天接口按表单频率限速。部署脚本在迁移后执行 `rebuild_search_index`。
- **前端**：产品目录筛选项按类别参数动态生成，增加单位切换；产品卡片和详情显示参数清单；常见问题页读后台；搜索页用新接口并显示纠错提示和资料结果；右下角入口在助手开启时打开侧边面板，关闭时仍是原来的联系按钮；隐私政策补充助手与搜索记录说明。
- **其他修正**：资料下载链接统一为 `/api/…`；演示数据放在独立的"Demo: Trailer Axles"类别；后台标题改为 WANSHANG；原写死的常见问题由迁移 0023 搬入后台。

## 验证情况（均为本次亲自运行）

- 后端全量测试：SQLite 352 项通过；PostgreSQL 16 上 351 项通过（新增一项前的版本）。
- 前端：类型检查、代码规范检查、25 项安全回归测试通过，生产构建成功。
- 部署：`deploy` 测试 33 项通过；生产编排文件和 nginx 配置在本机 Docker 中校验通过；后端镜像以助手服务方式启动并响应正常。
- 浏览器实测（本地 PostgreSQL + Redis + 本地模拟的 DeepSeek）：按公斤筛选命中以磅录入的产品、单位切换、助手搜索并引用产品页、面板内生成并提交询价单、询价单与对话关联、销售邮件内容。
